A Student Management REST API developed using Python, FastAPI, SQLAlchemy, and MySQL. This project provides a structured backend system for managing student records through CRUD (Create, Read, Update, and Delete) operations. It allows users to register new students, retrieve all registered students, search for individual students by ID, update existing student information, and delete student records. The API includes data validation using Pydantic schemas, duplicate checking for student numbers and email addresses, database session management, and appropriate HTTP error handling for invalid or conflicting requests. This project demonstrates fundamental backend development concepts, RESTful API design, relational database integration, and Python programming while building a foundation for future integration with a frontend interface or a complete Student Management System.
